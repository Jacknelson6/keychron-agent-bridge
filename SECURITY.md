# Security

Use [GitHub private vulnerability reporting](https://github.com/Jacknelson6/keychron-agent-bridge/security/advisories/new)
for vulnerabilities involving local IPC, hooks, device access, or firmware writes.
Do not post credentials, private settings, session metadata, or recovery dumps in
a public issue. Include a version, platform, model, transport, and a minimal
reproduction without private data.

This initial release is maintained on `main`; fixes are documented in releases.
GitHub Actions does not access physical devices or establish hardware support.
