## Final logo prompt

Use case: logo-brand. Create the primary logo symbol for an independent open-source
software project named Keychron Agent Bridge, which connects Claude Code and
Codex activity to mechanical-keyboard lighting. Deliver a single distinctive,
compact geometric mark on a genuinely transparent background, no words or letters.
Concept: four substantial rounded-square keycaps become the deck of a minimal
bridge, with a simple strong connecting rail below, using negative space to suggest
a bridge/connection. Precisely four keycap shapes, three electric blue (#4C8DFF)
and one warm orange (#F3944A), reflecting a blue keyboard with orange agent-status
keys. Clean front-on flat vector-like geometry, consistent corner radii, balanced
optical proportions, excellent readability at 32 pixels and 256 pixels, generous
transparent margin, suitable as a GitHub avatar and app icon. Bold, confident,
restrained developer-tool identity. No keyboard brand logo, no Claude or OpenAI
logos, no robot, brain, magic sparkles, circuit traces, gradients, 3D, shadows,
photographic material, extra mini marks, mockups, or surrounding text.

## Final banner prompt

Reference: logo.png. Create a beautiful, sophisticated GitHub repository hero banner
for Keychron Agent Bridge. Use the supplied blue-and-orange four-key bridge symbol
as the exact brand identity reference, preserving its recognizable four caps and
bridge form. Wide landscape composition, approximately 2.4:1 aspect ratio, generous
safe margins. Deep ink navy background #0B111C. Left 52%: a small clean version of
the logo symbol near the upper-left, then large impeccable off-white Swiss grotesk
typography on two lines, exact text: 'Keychron' and 'Agent Bridge'. Beneath, exact
smaller text: 'Claude Code + Codex'. Bottom-left a tiny understated monospace label,
exact text: 'OPEN SOURCE / MACOS / QMK'. Right 48%: an elegant precise oblique
top-down illustration of a compact 75-percent mechanical keyboard with a knob,
almost-black keycaps and restrained electric blue backlighting. Draw the top-row F9
and F10 keycaps glowing warm orange, while F11 and F12 remain blue. Make these
four keys clear as the focus; other keyboard detail subtle. Restrained geometric
product illustration, unusually refined typography and spacing, crisp edges,
subtle light only around the active keys, no busy background. Visual concept is
a quiet physical status display for AI agents. Do not use official Keychron/Claude/
OpenAI logos or imply official affiliation. Do not add other words, badges, UI
windows, robots, brains, sparkles, decorative arrows, or circuit-trace clutter.
All copy must be exactly as quoted, legible, not warped or cut off.
