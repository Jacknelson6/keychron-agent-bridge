# Changelog

## 0.1.0 · 2026-11-16

Initial public source release.

- Claude session indicators on F9–F12 with a steady blue base.
- Claude Code and Codex prompt shortcuts and Fn-knob selection.
- Verified V1 Max ANSI knob USB support on factory v1.1.1.
- Optional Bluetooth main-firmware extension and radio verification.
- Login startup, crash recovery, and verified busy-session restoration.
- Custom palette example, extension guides, protocol fixtures, and CI.

The default lights count Claude only. Other keyboards and host apps need verified
ports. Source is provided; factory firmware, backups, and notarized app binaries
are not part of this release.
